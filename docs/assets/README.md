# Swagger UI assets

Version: **5.33.1**

Upstream: https://github.com/swagger-api/swagger-ui/tree/v5.33.1/dist

The JavaScript bundle and CSS are copied unmodified from this pinned release.
`LICENSE` contains the upstream Apache 2.0 license; bundled third-party notices
are in `swagger-ui-bundle.js.LICENSE.txt`.

All runtime files are served locally. The application disables the external
Swagger validator and loads `/openapi.json` from the same origin.
